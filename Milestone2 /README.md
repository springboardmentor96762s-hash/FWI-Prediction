This project contains the script Milestone_2.py, which performs complete exploratory data analysis and regression modeling on the Portuguese Forest Fires dataset. The script loads the CSV file, prints dataset information, summary statistics, and missing values, and then generates visualizations including histograms for all numeric features, a correlation heatmap, and a pairplot to understand feature relationships. It prepares the data for modeling, splits into training and testing sets, builds a Linear Regression model, and evaluates it using MSE, RMSE, residual plots, and scatter plots for prediction quality. The script also runs Ridge Regression for multiple alpha values and compares train and test MSE, RMSE, and MAE to detect overfitting or underfitting and to determine the optimal regularization strength. To run the script, install pandas, numpy, matplotlib, seaborn, scikit-learn, and scipy, update the dataset path inside the Python file, and execute it through Python or a Jupyter Notebook. This milestone demonstrates EDA, baseline regression, residual analysis, and regularized regression to understand fire weather index prediction behavior in a clean and structured manner.
